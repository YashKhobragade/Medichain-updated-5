# Key Learnings & Insights

## Technical Learnings

### Smart Contract Development

#### What Worked Well
- Gas optimization through efficient struct packing reduced costs by 30%
- Modifier-based access control proved clean and maintainable
- Test-driven development caught 3 major bugs before deployment
- Event-driven architecture enabled off-chain indexing

#### Key Challenges
- Solidity enum handling more complex than expected
- Gas estimation required iterative optimization
- Transaction UX needed careful state management

### Frontend Development

#### Next.js 14 Success Factors
- App Router improved performance significantly
- Server components reduced initial load times
- TypeScript integration caught Web3 errors early

#### Web3 Integration Insights
- RainbowKit reduced wallet code by 80%
- Transaction feedback crucial for user confidence
- Mobile web better for QR scanning than desktop

### What Worked in Hackathon Context
